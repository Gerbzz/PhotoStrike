# PhotoStrike source scope

This candidate is copied from a frozen PhotoCraft source checkout at commit `953390a36ef59c6ca04c5850b5b5d9d0dd9e625a`, with PhotoStrike adaptation files and the accepted `Cargo.lock`. The original PhotoCraft code and feature assets retain their MIT/Apache and applicable third-party terms. Original `LICENSE-MIT`, `LICENSE-APACHE`, `NOTICE`, `ATTRIBUTION.md`, icon/font/dictionary notices, and donor copyright text are preserved. This file distinguishes PhotoStrike changes; it does not grant a first-party license for them.

The adapted packages `apps/photocraft` and `crates/{automation,engine,format,io,ui-egui}` do not inherit a blanket license field in this candidate. Unmodified donor package metadata remains as upstream. The PhotoStrike title bar and native window embed the unchanged approved butterfly PNG from `assets/branding/PhotoStrike.png`; the desktop Windows resource embeds only packaging-size derivatives in `PhotoStrike.ico` (see `assets/branding/README.md`). Donor `assets/app-icon/` art remains as attributed source because the unmodified upstream CLI Windows build references `photocraft.ico`; that CLI art is not approved for a PhotoStrike installer or release. No installer, Linux desktop integration or macOS bundle is added by the runtime branding change. The Windows desktop version resource identifies upstream PhotoCraft separately from PhotoStrike changes.

ArtCraft trademark images under `docs/brand/`, donor marketing screenshots under `docs/images/`, and old CI/release/installer scripts were omitted. The original donor notices can still mention excluded upstream assets; those are provenance records, not bundled-asset claims. `docs/brand/LICENSE-brand.txt` is retained to document why the marks were omitted. No user projects, private captures, model downloads, target caches, secrets, or corpus files are included.

This is a source checkpoint. The donor app's existing crate names and file formats remain; RAW development and catalog integration with LightCraft have not been implemented. Installers, app-store packages, and release automation are unsupported. Locked tests, a native build with required Windows resource compilation, and a synthetic native-control regression passed on a clean standalone source copy before these documentation updates. Interactive desktop and accessibility acceptance and binary-distribution notices remain separate gates.
